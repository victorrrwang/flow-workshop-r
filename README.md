# Bioinformatics and Analysis of Flow Cytometry Data in R/Python

Use this folder for workshop-specific slides, R/Python scripts, example FCS files, notes, and references.

## Draft Scope

This workshop will cover basic approaches for analyzing flow cytometry data using command-line tools, R, and Python.

Possible topics:

- Reading and writing flow cytometry data
- Manipulating and processing data
- Visualizing flow cytometry results
- Basic reproducible analysis workflows
- High-dimensional analysis approaches
